# Samora AI

> Samora AI builds multilingual voice agents that automate high-volume inbound and outbound calling. Its server-to-server REST API triggers outbound calls, manages outbound calling campaigns and scheduled recipients, and delivers real-time call events via signed webhooks. Authentication is an organization API key sent in the X-API-Key header. Base URL: https://api.samora.ai.
